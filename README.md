## 快速开始

### 环境要求

- **Node.js** >= 18
- **npm** >= 9

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/your-username/geek-cube.git
cd geek-cube

# 安装依赖
npm install

# 启动开发服务器 (默认 http://localhost:5173)
npm run dev

# 类型检查
npx tsc -b --noEmit

# 运行测试
npm test

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

### 可用脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动 Vite 开发服务器 |
| `npm run build` | TypeScript 类型检查 + Vite 生产构建 |
| `npm run preview` | 预览生产构建产物 |

## 架构设计

### 路由设计
```
/                    → 首页仪表盘（HomeWrapper + Home）
/category/:id        → 工具分类列表页
/tools/:tool-path    → 各工具页面（懒加载）
/settings            → 背景与主题设置
/plugins/:id         → 插件运行页面
```

所有工具页面通过 `React.lazy()` 动态加载，仅在访问时才加载对应 chunk，保证首屏性能。

### 数据流
```
tools.ts (SSOT - 单一数据源)
  ├── toolCategories[]  → 侧边栏分类渲染
  ├── allTools[]        → 全局搜索索引
  ├── toolRoutes[]      → React Router 路由生成
  └── TOOL_COMPONENTS   → 懒加载组件映射
```

所有工具信息（名称、路径、图标、描述、分类）集中在 `tools.ts` 中定义，路由、搜索、导航均由此派生，保证一致性。

### 快捷键系统
| 快捷键 | 功能 |
|--------|------|
| `⌘K` / `Ctrl+K` | 打开全局搜索 |
| `↑↓` | 搜索结果导航 |
| `↵` | 打开选中工具 |
| `Esc` | 关闭搜索/弹窗 |

## 自定义与扩展

### 背景主题
通过右上角 ⚙️ 设置面板自由切换背景效果组合：粒子场、矩阵雨、星空、电路板、二进制雨、扫描线、HUD 状态栏等。

### 添加新工具
1. 在 `src/utils/tools.ts` 中添加工具定义（`id`, `name`, `path`, `icon`, `description`, `color`）
2. 在 `src/pages/` 中创建工具页面组件
3. 在 `src/App.tsx` 中 `lazy()` 导入组件，并注册到 `TOOL_COMPONENTS` 映射
4. 侧边栏、搜索、分类页自动生效

### 开发插件
系统内置插件机制，通过插件管理器创建自定义脚本，支持动态注册和启用。
